# Personal Webpage Starter

A minimal Vite + React starter with TanStack Router ready to use.

## Available scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Project structure

- `src/main.tsx` — application entry point
- `src/router.tsx` — TanStack router setup and navigation layout
- `src/pages/*` — sample page components
- `src/styles.css` — base styles and navigation menu

## Customize

Update the sample pages in `src/pages` and add new routes in `src/router.tsx`.
